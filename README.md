# Rubies

Mine, collect and trade rubies.

## Features

- Ruby
- Ruby ore and deepslate ruby ore with ore generation similar to emeralds
- Ruby block
- Trade with armorers and butchers for better deals with rubies
- Ruby trim material with red shades
